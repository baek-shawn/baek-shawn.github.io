## 환경

| 항목 | 값 |
|---|---|
| GPU | RTX 3060 12GB |
| OS | Ubuntu 24.04 |
| Python | 3.12 |
| vLLM | 최신 안정 버전 |

## 설치

```bash
python -m venv .venv
source .venv/bin/activate
pip install vllm
```

설치 후 CUDA 인식을 먼저 확인합니다.

```bash
python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))"
```

```text
True NVIDIA GeForce RTX 3060
```

## 실행

12GB VRAM에서는 7B 모델을 FP16으로 그대로 올릴 수 없으므로 양자화 모델을 사용하고 컨텍스트 길이를 제한합니다.

```bash
vllm serve Qwen/Qwen2.5-7B-Instruct-AWQ \
  --max-model-len 4096 \
  --gpu-memory-utilization 0.90 \
  --dtype half
```

주요 옵션은 다음과 같습니다.

- `--max-model-len`: KV cache 크기를 결정한다. VRAM이 부족하면 가장 먼저 줄인다.
- `--gpu-memory-utilization`: vLLM이 사용할 VRAM 비율. 데스크톱 환경에서는 0.85~0.90 정도가 안전하다.
- `--dtype half`: Ampere 계열은 bfloat16보다 float16이 무난하다.

## 확인

OpenAI 호환 API로 요청을 보내 봅니다.

```bash
curl http://localhost:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model": "Qwen/Qwen2.5-7B-Instruct-AWQ", "messages": [{"role": "user", "content": "안녕하세요"}]}'
```

## 자주 만나는 오류

```text
torch.OutOfMemoryError: CUDA out of memory.
```

이 경우 순서대로 시도합니다.

1. `--max-model-len`을 4096 → 2048로 줄인다.
2. `--gpu-memory-utilization`을 0.90 → 0.95로 올린다 (다른 GPU 프로세스가 없을 때만).
3. 그래도 부족하면 더 작은 모델(3B, 1.5B)로 바꾼다.

> 12GB에서 7B AWQ 모델은 실용적인 범위에서 동작하지만, 긴 컨텍스트가 필요한 작업에는 한계가 있다.
