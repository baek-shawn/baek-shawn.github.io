## 왜 블로그를 새로 만들었나

코로나 시절 해양생물전공으로 대학을 졸업하고 나서 앞으로 뭘 해야 할지 고민이 많았다. 그러다 형의 권유로 코딩을 처음 접했고, 방송대 컴퓨터과학과에 다니면서 프로그램과 코딩이 뭔지 조금씩 알게 됐다.

개발자가 되어보고 싶어서 소프트스퀘어드라는 회사의 교육 프로그램에도 지원했다. 서버 세션을 두 달 정도 공부했는데, 그때 배운 내용을 정리해보려고 만든 게 티스토리 블로그였다.

https://shawnbaek.tistory.com/

처음에는 “비전공자 shawn의 개발 블로그”라는 이름으로 시작했다. 그런데 막상 지금 들어가 보면 서버 공부를 정리한 글은 거의 없고, 얼마 지나지 않아 ML 관련 글만 남아 있다. 형의 권유로 운 좋게 데이터사이언스 석사 과정에 들어가게 되면서 관심사가 자연스럽게 그쪽으로 옮겨갔기 때문이다.

석사 과정 중에도 블로그를 조금씩 쓰기는 했다. 하지만 연구가 바빠지면서 어느 순간부터 손을 놓게 됐다.

예전부터 Jekyll과 GitHub Pages로 직접 만든 블로그를 운영하는 사람들이 멋있어 보였다. 나도 해보고 싶었지만, 그런 블로그를 만들려면 시간을 꽤 많이 써야 할 것 같아서 계속 미뤘다. 그런데 요즘은 바이브코딩을 이용하면 예전보다 훨씬 빠르게 만들 수 있어서 한번 도전해보기로 했다. 그래서 이번에는 티스토리가 아니라 내가 직접 운영하는 블로그를 만들어보기로 했다.

예전에 서버를 공부할 때 가비아에서 도메인을 사서 연결해본 적도 있다. 이번에는 그때처럼 연습으로 끝내지 말고, 내 개인 도메인까지 연결해서 제대로 시작해보자는 생각이었다.

이 블로그의 가장 큰 목적은 내가 공부한 내용과 여러 경험을 기록하는 것이다. 여기에 애드센스를 붙여서 조금이라도 수익이 나면 좋겠다는 생각도 있다. 티스토리를 시작했을 때도 비슷한 생각을 했었다.

처음에는 GPT와 애드센스부터 이야기했다. 그러다 우선 애드센스보다 개발 블로그를 다시 시작하는 게 먼저라는 생각이 들어서, 이번 프로젝트를 시작하게 됐다.

## 어떻게 만들었나

![GPT가 추천해준 개발 블로그 스택 구성](/images/[1]blog-project-start/image-2.webp)

처음에는 GPT 웹 버전으로 애드센스 블로그에 어떤 주제로 글을 쓰면 좋을지 이야기했다. 일상이나 리뷰 같은 글은 네이버 블로그에 남기고, 개발·엔지니어링·프로젝트 관련 글은 새로 만드는 블로그에 쓰기로 했다.

그 과정에서 GPT가 추천해준 구성대로 블로그를 만들어보기로 했다. 예전에는 Jekyll과 GitHub Pages로 직접 블로그를 만드는 사람들이 멋있어 보이기만 했는데, 이번에는 바이브코딩의 도움을 받아 나도 직접 만들어보게 됐다.

![Astro를 추천받고 정적 사이트 생성 라이브러리를 찾아보는 과정](/images/[1]blog-project-start/image-3.webp)

추천받은 스택 중에는 Astro라는 TypeScript 기반 정적 웹페이지 생성 라이브러리가 있었다. 처음 들어본 이름이라 따로 찾아봤는데, Astro를 이용해 간단한 블로그를 만드는 사람들이 꽤 많았다. 일단 나도 그대로 사용해보기로 했다.

처음부터 기능을 많이 넣으려고 하면 또 알아보다가 지쳐서 시작도 못 할 것 같았다. 그래서 검색 기능 같은 건 일단 빼고, 글을 쓰고 읽을 수 있는 정도의 MVP만 먼저 만들기로 했다. 필요한 기능은 블로그를 운영하면서 하나씩 추가할 생각이다.

![MVP md파일 캡쳐본](/images/[1]blog-project-start/image-4.webp)

검색에 잘 걸리도록 SEO 같은 요소도 신경 썼다. 모르는 개념은 GPT에게 물어보고, 실제 구현은 Claude Code에게 맡겼다. 이 과정에서 이 블로그가 어느 정도까지 필요한지, 어떤 기술을 사용할지 정리한 스펙 문서도 만들었다.

만들면서 새로 알게 된 내용은 따로 정리해서 나중에 블로그에 써볼 생각이다. 다만 솔직히 말하면 내가 직접 코드를 작성해서 만든 블로그는 아니다. 어떤 블로그를 만들고 싶은지는 GPT와 이야기하면서 정했고, 구현은 대부분 Claude Code를 통해 진행했다.

처음 만든 구조는 카테고리별로 폴더를 나눌 수 없었다. 글을 쓰려면 편집기를 열고 md 파일을 만들어야 하는데, 모든 글을 한 폴더에 넣는 방식은 나중에 관리하기 불편할 것 같았다.

이미 URL을 연결하고 배포까지 한 뒤였지만, 결국 구조를 한 번 더 수정했다. 카테고리별로 폴더를 만들고 그 안에서 글을 쓸 수 있게 바꿨다. 파일명 앞에는 번호를 붙여서 정렬할 수 있도록 했고, 실제 URL은 파일명이 아니라 frontmatter에 적은 slug 값을 사용하도록 수정했다.

## 앞으로 어떤 글을 쓸지

일단은 지금 나눠둔 카테고리를 기준으로 글을 써볼 생각이다. 현재 카테고리는 Development, AI, Engineering, Certification, Projects, Papers로 나눠두었다.

최근 회사에서 육상무선통신사 자격증이 필요하다고 해서 공부를 시작했다. 그래서 AI, 개발, 프로젝트, 논문뿐 아니라 자격증을 준비하면서 배운 내용도 정리해볼 예정이다. 나중에는 여기서 배운 내용을 AI나 데이터 분석 쪽으로 어떻게 활용할 수 있을지도 써보고 싶다.

하고 싶은 건 많은데, 계획만 세워두고 실제로 실행하지 않는 경우가 많았다. 이번에는 완벽하게 준비하려고 하기보다 일단 하나씩 글을 쓰면서 이어가 보려고 한다.

![카테고리별로 정리한 블로그 구성](/images/[1]blog-project-start/image-5.webp)

## 마무리

꾸준히 할 수 있을지는 아직 모르겠다. 예전에도 블로그를 시작했다가 중간에 멈춘 적이 있기 때문이다.

그래도 이번에는 너무 거창하게 생각하지 않고, 공부한 내용이나 프로젝트를 하나씩 남겨보려고 한다. 일단 첫 번째 목표는 이 블로그를 계속 운영하는 것이고, 그다음에 애드센스도 붙여보자.
